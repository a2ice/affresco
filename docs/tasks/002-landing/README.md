# 002 — Адаптивный лендинг AFreska

Статус: discovery / требования по референсу подготовлены, дизайн и реализация НЕ выполнены.

## Источник и ограничения

27.10.2026 владелец прислал в чат проекта вертикальный скриншот главной AFFRESCO (изображение в переписке; URL исходного сайта пока не подтверждён). Ни оригинальных изображений, ни прав на их использование не предоставлено. Это ориентир по качеству, структуре и настроению, **не разрешение копировать** чужие фотографии, логотипы, тексты или точную композицию.

Цель проекта AFreska — собственный демонстрационный сайт премиальных настенных фресок, показывающий клиентский путь от подбора изображения до параметров и AI-примерки в интерьере. Функции редактора, аккаунтов, AI и email — отдельные задачи 003–006. Не смешивать AFreska с основным a2ice.ru и театром.

## Разбор видимого референса (сверху вниз)

1. Тонкая шапка: логотип, основные разделы, иконки аккаунта/избранного/поиска и контакты.
2. Первый экран: масштабная фотография гостиной с художественной настенной фреской, слева крупный антиквенный/редакционный заголовок, подзаголовок и CTA в каталог.
3. Категории изображений: «Цветы», «Природа», «Классика», «Искусство» — широкие фото-плитки с текстом поверх.
4. Каталоги/подборки: предметные изображения печатных альбомов, композиция на светлом фоне.
5. «Материалы и фактуры»: рулоны и крупные фрагменты поверхности материала.
6. Процесс/мастерство: мастер за росписью, видеопревью и рассказ о производстве.
7. Парные промо-блоки: создание индивидуальной фрески и предложение дизайнерам/архитекторам.
8. «Популярные дизайны»: горизонтальный ряд интерьерных примеров.
9. «Где увидеть и купить»: интерьер и поиск салона с картой.
10. Развёрнутый футер с навигацией и контактами.

Визуальный принцип: мягкие бежево-серые, белые и оливковые тона; теплая дневная фотография; сочетание выразительного serif для заголовков и компактного sans-serif для интерфейса; свободное пространство, тонкие линии, спокойные переходы. Стиль должен быть **оригинальным**, а не пиксельной копией.

## Предлагаемая структура MVP AFreska (обсудить перед окончательной визуальной концепцией)

- Навигация: «Коллекции», «Материалы», «Создать фреску», «Как это работает»; демо-аккаунт только когда готова задача 004.
- Hero: короткое ценностное предложение и главный CTA «Создать свою фреску», второй — «Смотреть коллекции».
- Небольшой демонстрационный каталог: 4 тематические коллекции + карточки материалов с лицензированными/собственными изображениями. Карточки в будущем открывают редактор 003.
- «Как это работает»: выбор изображения → размеры/кадрирование → примерка в комнате → результат.
- «Материалы и фактуры»: только проверяемые сведения, без необоснованных технических и коммерческих обещаний.
- Блок действия для дизайнеров, контакты A2ice/AFreska только после подтверждения реквизитов.
- Футер: демо-статус, ссылки на политику обработки данных перед запуском загрузки фотографий.

Отложить/не имитировать без данных: поиск физических салонов по карте, продажу реальных каталогов, видео производства, цены и отзывы. Не оставлять фиктивных кнопок: либо поддерживаемый сценарий, либо видимая пометка «в разработке».

## Адаптивность и UX

- Desktop: крупное интерьерное фото, читаемый текстовый контраст, иерархия CTA, аккуратная сетка коллекций.
- Mobile: приоритет заголовка/CTA и фактуры изображения без перекрытий, компактная навигация, карточки в 1–2 колонки; без горизонтального переполнения.
- Доступность: клавиатурная навигация, видимый focus, осмысленные alt, достаточный контраст, не полагаться на иконки без подписей, учитывать reduced motion.
- Производительность: адаптивные изображения с корректными размерами, lazy loading ниже первого экрана, минимум сторонних библиотек, без тяжёлого видео в hero.
- SEO/безопасность: семантические заголовки и метаданные, но демонстрационный сайт без подтверждённого релиза должен соблюдать ранее согласованный noindex.

## Контракт между этапами

- 002 отдаёт визуальную систему, responsive-страницу, тестовые коллекции и явные точки интеграции.
- 003 реализует модальный редактор/кроп/размеры и восстановление черновика.
- 004 реализует вручную созданные аккаунты/сессии/квоты без публичной регистрации.
- 005 делает AI-примерку через серверный PHP, с квотами и оговоркой о неточности генеративного переноса узора.
- 006 делает отправку результата по email через защищённый backend.

Для демо — HTML/CSS/JS (Alpine.js) и минимальный PHP/JSON согласно docs/Tasks.md; Laravel/WordPress не вводить.

## Приёмка 002

1. Оригинальные desktop/mobile-макеты сопоставлены с принципами скриншота, но не копируют его дословно.
2. На desktop и mobile корректно видны hero, навигация, категории, путь к редактору и футер.
3. Все активные действия имеют понятное поведение, демо-элементы и ограничения явно обозначены.
4. Источники изображений/шрифтов и права на их использование записаны.
5. Нет критических ошибок консоли, нарушения адаптивности и блокирующих дефектов доступности.
6. После публикации — независимый E2E по точному URL/коммиту и PASS до статуса accepted.
