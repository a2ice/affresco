# 002 — Адаптивный лендинг

Статус: **in_progress**. 27.10.2026 разработан первый MVP лендинга и редактора; выполнен редакционный дизайн-проход v0.2 в `main`. Визуальная и независимая E2E-приёмка обновлённой версии ещё не проведены.

По предоставленному заказчиком референсу создать главную страницу для премиальных настенных фресок, демо-каталог из ограниченного набора материалов, адаптивность, доступность и высокую производительность.

## Дизайн-основа

- Референс в репозитории: [docs/ref/homepage_proto.jpg](../../ref/homepage_proto.jpg).
- Рабочий гайдлайн: [docs/DESIGN_GUIDELINE.md](../../DESIGN_GUIDELINE.md).
- Исходные CSS-токены: [public/assets/css/design-tokens.css](../../../public/assets/css/design-tokens.css).
- Токены предложены по визуальному JPG, не являются измеренными значениями из оригинального макета.
- В публичном интерфейсе использовать название **AFFRESCO** («Аффреско»). До подтверждения прав отображать текстовый логотип; изображения и материалы из референса не копировать автоматически.

## Реализация v0.2 (проверка ещё требуется)

- Главная: `public/index.html`, базовые стили `public/assets/css/site.css`, токены `public/assets/css/design-tokens.css`, визуальный слой `public/assets/css/editorial.css`.
- Каталог: `public/api/catalog.php` формирует JSON из загруженных владельцем файлов в `Images/catalog/` или `Images/каталог/`; артикул выводится из имени файла без расширения.
- Поведение: `public/assets/js/site.js` выводит карточки, загружает изображение для hero и второго фоторяда; по клику открывает редактор с кадрированием и сохранением в браузере.
- Попап входа сейчас демонстрационный: не собирает пароли; реальная авторизация относится к задаче 004.
- Дизайн v0.2: убраны CSS-имитация интерьера и верхняя демо-плашка, усилены типографика, фотографическая композиция, карточки, редактор и мобильные стили. Содержательный статус демонстрации остаётся на странице.
- Проверено: запись файлов в `main`, синтаксис клиентского JS. **Не проверено**: новое визуальное отображение на реальном сайте и на целевых ширинах, доступность файлов FTP, независимая E2E-приёмка.

## Приёмка реализации (пока не проводилась)

1. Страница desktop/mobile визуально сопоставлена с референсом и использует общие токены.
2. Навигация и карточки корректны, рабочие действия честно обозначены, демо-контент маркирован.
3. Право использования опубликованных изображений проверено, чужие логотипы не заимствованы.
4. Нет ошибок консоли, переполнения на 360/390/768/1024/1440px; клавиатурная навигация доступна.
5. Проверен точный опубликованный URL, commit и критические сценарии независимым E2E после согласованного деплоя.

## Границы

Демо разрабатывается и публикуется напрямую из `main` по решению владельца. Это рабочая итерация, не финально принятая страница. Блоки AI-примерки, аккаунтов и email реализуются отдельно согласно `docs/Tasks.md`. После следующего функционального этапа провести независимый E2E.
