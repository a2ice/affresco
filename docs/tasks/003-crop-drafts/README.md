# 003 — Редактор фрески и черновики

Статус: planned.
По клику на карточку открыть модальный редактор. Alpine.js управляет UI, кропом, масштабом, пропорциями и параметрами размеров. Сохранить черновик для вошедшего пользователя либо анонимной сессии.

Приёмка: повторное открытие восстанавливает параметры; ограничения исходного качества и разрешения понятны; значения проверяются и на сервере.
