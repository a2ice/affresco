# 006 — Отправка готового результата на email

Статус: planned.
После успешной визуализации показывать «Отправить на почту». Отправлять результат через серверный PHP SMTP с оформленным письмом, данными фрески и защищённой ссылкой/вложением; не раскрывать email посторонним. Ограничение частоты, валидация адресов и обработка сбоев SMTP.

Приёмка: письмо получено на тестовый адрес, изображение соответствует сохранённому результату, ошибки и повторные отправки обработаны, нет открытого SMTP relay.
