# Единый кабинет — 28.10.2026

Один accountModal заменяет отдельные окна входа и аккаунта. В верхней зоне гость видит логин/пароль, пользователь аккаунта — email с иконкой сохранения внутри поля. Вход и выход обновляют шапку, коллекции и статистику без перезагрузки. Пароль после входа очищается.

Плашки открывают вкладки «Инфо», «Избранные», «Сохранённые кадры», «Генерации». Активная плашка белая. Вкладки доступны с клавиатуры: стрелки, Home/End, tablist/tab/tabpanel и aria-selected.

Гостевое избранное находится в PHP-сессии, кадры — в браузере. Аккаунт использует собственное хранилище, автоматического переноса гостевых данных нет. Устаревшие ответы и отложенные операции избранного отбрасываются после смены состояния.

В «Инфо» показаны входы, сохранения и отправки с датами. Для аккаунта используются login_count, last_login, updates_count, last_update и новые emails_count, last_email. Отправки увеличиваются только после приёма письма SMTP. Для гостя отправки учитываются отдельно в сессии, сохранения — локально с момента включения счётчика. Более ранние отправки не восстанавливаются. Генерации пока не подключены.

Перед изменением владелец подтвердил работу почты с affresco@a2ice.ru через localhost:25, security=none. SMTP-конфиг и пароль этим изменением не затрагиваются.

Проверки включены в CI: node tests/cabinet.mjs (состояния гостя/аккаунта, вкладки и клавиатура, вход/выход без reload, email success/error, статистика кадров) и php tests/account-activity.php (изолированные fixtures, счётчики, оба формата accounts.json, приватные поля и разделение активности). Реальный вход и сохранение email с приватным аккаунтом не подтверждаются тестами с фикстурами.
