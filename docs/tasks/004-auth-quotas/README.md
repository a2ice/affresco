# 004 — Демо-аккаунты и статистика

Статус: planned.
Только ручное создание учётных записей в приватном серверном JSON, пароль в `password_hash()` и проверка через `password_verify()`; не хранить пользовательские данные в Git или публичной папке. PHP-сессии, CSRF-защита, атомарная запись и блокировки файлов.

Сохранять статистику генераций: попытки, успешные, неуспешные, лимиты и технические идентификаторы. Ограничивать частоту запросов, не списывать успешную квоту за системные ошибки.

Приёмка: отсутствует публичная регистрация; приватный JSON недоступен через HTTP; секреты не попадают в клиентский JS; квоты реально соблюдаются.
