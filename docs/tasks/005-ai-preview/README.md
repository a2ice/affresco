# 005 — AI-примерка фрески в комнате

Статус: planned.
Посетитель загружает изображение интерьера и выбранный кроп фрески. Серверный PHP-обработчик обращается к OpenAI API; API-ключ хранится вне публичного кода. Ограничить размер и тип файлов, число одновременных запросов и стоимость. Показать обработку, ошибки, сохранённые результаты.

Отдельно проверить верность рисунка фрески: генеративное редактирование может изменять узор и не должно позиционироваться как технически точная проекция.

Приёмка: триггер, статусы и результат воспроизводимы; оригинал и результат сохраняются безопасно; квоты корректны при ошибках; проверены мобильный и desktop.
