# Portfolio try-on embed — A2ICE case

Дата: 2026-10-29. Изолированное улучшение демо Affresco по просьбе владельца A2ice.

## UX
В обычном интерфейсе всё остаётся без изменений. При `/?embed=tryon&sku=6247` (опциональный безопасный SKU — если отсутствует, первая фреска из существующего каталога) интерфейс открывает сразу существующий `#tryonModal` на этапе `Загрузите фото комнаты`; блоки главного сайта скрыты стилями специального режима. Скрыты **только** внутренние крестик примерки и «Вернуться к кадру», потому что в iframe нет полноценного редактора кропа. Внешний попап A2ICE имеет собственный крестик и Escape.

## Изоляция и безопасность
- Никаких изменений API, квот, авторизации и платной AI-генерации. Фреска выбирается по публичной каталожной метаинформации через existing `/api/catalog.php`.
- `start` вызывается штатно из `window.affrescoTryon.start`. Первым действием пользователя остаётся загрузка его собственной фотографии; никакая фотография не загружается автоматически.
- CSS/JS включены только при точном `embed=tryon`; обычная страница не теряет функционал и по-прежнему noindex.
- Экраны авторизации и email внутри iframe должны оставаться доступны.
- Источник iframe с `https://a2ice.ru/cases/affresco`, cross-origin DOM-доступ не требуется. Если сервер отдаёт запрет встраивания через заголовки X-Frame-Options или CSP, это blocker для E2E: необходимо проверить и разрешить только a2ice.ru на уровне сервера без разрешения произвольных framing origins.

## Проверка
1. CI JS/PHP lint + существующие тесты, главное демо на / и /#catalog.
2. После деплоя проверить в браузере embed ?sku=6247: сразу загрузка комнаты, без внутреннего X; фото, четырёхугольная стена, расположение фрески; авторизация для AI по-прежнему обязательна.
3. Desktop/mobile и внешний pop-up по URL основного кейса — независимый E2E после обоих деплоев.
