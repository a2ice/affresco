# 009 — Тень от фрески под направленным светом

Дата: 28.10.2026. Инициатива владельца: добавить к существующему инструменту «Свет» перспективную тень от фрески, как будто изображение вынесено от стены на 10–15 см. **Самой толщины, настройки глубины, 3D-модели и нового элемента UI нет.**

## Продуктовая модель

- Условная виртуальная толщина **12 см** зашита внутри расчёта; направленный свет использует уже имеющиеся start/end, интенсивность и тон.
- Направление смещения тени — от start к end (от светлой части существующего градиента к затемнённой).
- Сдвиг рассчитывается в физических координатах калиброванной стены (сантиметры) и затем проецируется через её гомографию. Поэтому при перспективном наклоне, при частично невидимых углах стены и при перемещении/масштабировании редактора тень не превращается в обычный прямоугольный CSS box-shadow.
- Тень мягкая, нейтральная, с лёгким размытием и малой непрозрачностью. Параметры регулируются **внутренне** силой света, а не пользовательскими ползунками. Угол луча к нормали стены из одного двумерного жеста восстановить нельзя; это декоративная правдоподобная **2D-аппроксимация**, а не точное трёхмерное моделирование света.
- Порядок слоёв: фото комнаты → тень, обрезанная по калиброванной стене → фреска → существующее освещение фрески. При снятии света («Отменить свет») тени нет.
- Один и тот же `core.draw` используется для предпросмотра и JPEG; размеры стены, фрески, счета генераций, IndexedDB, серверный API, режим pan/zoom не изменены.

## Файлы

- `public/assets/js/tryon-core.js`: `shadowProjection`, `drawShadow`, общий рендер.
- `public/assets/js/tryon.js`: передаёт плоскость стены в рендер и экспорт.
- `public/index.html`: обновлён cache-busting query у двух JS файлов.
- `tests/tryon-core.cjs`: направления свет → тень, гомография со стеной вне фото, отсутствие без света, порядок рендера и равенство поведения предпросмотра/JPEG.

## Проверки и статус

- CI на PR: `node --check`, существующие Node/PHP тесты и новые тесты тени.
- Перед выпуском убедиться, что **CI PASS**, а PR затрагивает только этот эффект, тесты, документацию и cache bust.
- Независимый E2E пока недоступен (соглашение владельца по предыдущему выпуску); отсутствие E2E нельзя записывать как PASS.
- После публикации владелец проверяет на `https://affresco.a2ice.ru/`: включить свет, провести из разных направлений, оценить тень по краям фрески; затем нажать «Отменить свет», убедиться в исчезновении тени; сохранить/скачать JPEG и сравнить эффект. В браузере и на смартфоне заметить возможные нарушения перспективы/клиппинга.

## Коррекция по визуальной проверке владельца — 28.10.2026

На присланном скриншоте тень выглядит как от выноса 50–75 см: фактическая проблема — одновременно слишком большой экранный сдвиг, непрозрачный полигон с чётким контуром и недостаточно мягкая полутень. Исправление в ветке `fix/tryon-soft-compact-shadow-20261028`:

- Номинальная толщина фрески для UX остаётся условно **12 см**, но проекция тени учитывает неизвестный угол освещения: смещение в плоскости стены теперь **1,2–4,56 см**, а не 3–14,4 см.
- Добавлено ограничение *максимального смещения каждого угла* в пикселях исходной фотографии (не более 1,2% короткой стороны, максимум 10 px) для защиты от перспективного разлёта.
- Прозрачность уменьшена до 0,025–0,095; размытие мягкой маски 7–15 px. При поддержке Canvas 2D `filter` размывается весь полигон, а не только обводка `shadowBlur` вокруг резкой заливки. Для старых контекстов есть fallback с почти прозрачной исходной заливкой.
- Направление света, клип по реальной стене, экспорт JPEG и независимость от pan/zoom сохранены.
- Автоматические тесты проверяют предел смещения, отсутствие жёсткого силуэта в основном пути, fallback и работу со стеной, выходящей за кадр. Ручное восприятие по реальному фото после публикации по-прежнему проверяет владелец.
